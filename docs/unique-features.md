# 独特功能说明

此文件记录本整合包区别于 `dyphire/mpv-config` 原始整合思路的主要变化，方便后续宣传、维护和同步上游时保留自己的特色。

本文统一使用「原创功能」标注本维护版独立设计、实现或深度整合的功能。相比「首创」，这个说法更稳妥，也更适合公开仓库长期维护。

## 近期新增原创功能

### 原创功能：HDR / PGS 图形特效字幕增强

本维护版针对 HDR 和 Dolby Vision 片源下 PGS / VobSub / DVB 等图形字幕的实际观感问题，增加了自编译核心补丁和播放器菜单：

- 图形字幕色彩空间可由核心单独控制，避免 `gpu-next` 路径下图形字幕错误继承 HDR 视频色彩空间。
- 默认保持视频画面、ASS/文本字幕和 OSD 不变，只修正 PGS 等图形字幕。
- HDR 图形字幕亮度可在菜单中独立选择 150 / 203 / 250 / 300 / 400 nits。
- 菜单会显示当前核心支持状态、图形字幕检测状态和当前亮度档位。

### 原创功能：音乐模式

音乐模式面向“用 mpv 听音乐”的场景，不把音频文件简单套用影视播放逻辑：

- 音乐文件进入模式后，最小化不暂停；影视文件仍保持原来的最小化暂停行为。
- 支持列表循环、随机循环和单曲循环。
- 随机循环不打乱前台播放列表显示，而是在后台维护随机待播队列。
- 随机队列使用 Fisher-Yates 洗牌，并记录已播放歌曲，尽量避免短时间重复。
- 进入音乐模式时使用自建 UI 风格提示，当前模式清晰可见。

### 原创功能：进度条左下角视频标签显示

进度条左下角的视频标签是本维护版针对日常观影信息密度做的原创 UI 整合：

- 在播放界面直接显示解码方式、画面规格、视频编码、音频格式、码率或网络状态。
- 信息贴合 uosc 进度条区域，不需要打开 stats 面板也能快速确认播放状态。
- 标签以轻量方式常驻显示，尽量不遮挡字幕、弹幕和画面主体。
- 适合排查硬解、HDR、音轨、码率和网盘串流状态时快速扫一眼。

### 原创功能：播放核心重构

本维护版维护了适配整合包的自编译 mpv 播放核心，不只是替换配置文件：

- 在 mpv 核心中加入 HDR 图形字幕色彩空间和亮度控制能力。
- 恢复 Windows Schannel / 系统证书链网络兼容，改善部分网盘、外置播放器和 HTTPS 媒体链接的播放成功率。
- 围绕 D3D11、`gpu-next`、HDR 图形字幕、网络播放和完整便携配置做发布前回归。
- 保留普通 mpv 使用习惯，新增能力通过配置和菜单接入，不强迫用户理解底层参数。

## 1. uosc 底栏重新组织

底栏是这一版最显眼的变化。常用入口被集中到底部一层，减少反复进入多级菜单：

- 文件打开、历史、目录入口保留在底栏左侧。
- 弹幕入口单独放到底栏，方便追剧时随时开关和匹配。
- 字幕、音轨、章节、倍速、播放列表、统计信息和更多菜单都放在可见区域。
- 播放态与空闲态分别优化：播放时突出播放控制，空闲时突出打开文件和网盘入口。

## 2. 中文弹幕体验

整合包面向中文追剧用户，弹幕相关入口更靠前：

- 支持网络弹幕搜索、匹配和加载。
- 支持为 URL 串流场景自动加载弹幕。
- 弹幕提示位置经过调整，尽量避开播放器顶部其他信息。
- 弹幕性能设置对 4K/高刷新场景做了限制，避免同屏弹幕过多拖慢 OSD 渲染。

## 3. 片头片尾标记与自动跳过

这一版把片头片尾作为底栏一等入口，而不是隐藏在深层脚本功能里：

- 支持 Anime Skip / TheIntroDB 片段查询。
- 支持本地手动标记片头片尾。
- 支持网站片段的本地手动修正覆盖。
- 支持把片段显示到时间轴，并配合自动跳过。
- 手动模板可复用，适合电视剧/动画连续剧场景。

## 4. 中文化 stats 信息

统计信息面板更适合中文用户阅读：

- 文件、显示器、视频、音频、解码、HDR、帧耗时等信息中文化。
- 便于快速判断硬解、刷新率、掉帧、色彩空间和码率。
- 配合底栏媒体标签，可在播放时快速了解当前播放状态。

## 5. AList/OpenList 网盘入口

空闲底栏新增网盘按钮，并把配置表单做进播放器 UI：

- 地址、账号、密码在 uosc 菜单中行内编辑。
- 保存后可直接打开 AList/OpenList 文件浏览。
- 播放 AList 文件时可回到当前文件所在目录。
- 发布版不会携带个人网盘地址、账号和密码。

当前实现基于 AList/OpenList API，不等同于通用 WebDAV PROPFIND 客户端。

## 6. 本地 ISO 播放链路

本地 ISO 播放入口做了统一处理：

- 拖拽、`Ctrl+O`、file-browser、最近播放等入口都尽量传入真实 `.iso` 路径。
- 由统一脚本改写为 `bd://` / `dvd://` 播放。
- 最近播放和历史记录尽量还原真实 ISO 路径，而不是只记录 `bd://`。

注意：AList/OpenList 远程 ISO 不作为当前发布功能，建议下载到本地后播放。

## 7. 文件浏览器鼠标体验

file-browser 做了更偏鼠标用户的操作优化：

- 鼠标悬停可高亮当前行。
- 点击目录进入目录，点击文件播放。
- 滚轮浏览时尽量保持 hover 反馈，不让列表突然跳动。

## 8. 公开发布清理

公开版应避免携带个人运行痕迹：

- 不带播放历史、watch_later、日志、截图和 shader cache。
- 不带个人 API key、token、Trakt secret、网盘账号密码。
- 不绑定固定显卡、固定音频设备或本机绝对路径。
- 字体、二进制播放器和大型资源建议通过 Release/网盘分发，仓库只保留说明和必要配置。
